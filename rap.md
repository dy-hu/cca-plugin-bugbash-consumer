# Rap About Messy Code

*Verse 1*
Yo, I opened the repo, what did I see?
A thousand-line function staring back at me.
No comments, no docs, just a tangled mess,
Variable named `x2` — yeah, you can guess.

Magic numbers everywhere, `42` and `99`,
No one knows what they mean, least of all nine.
Copy-paste all over, duplicated twice,
Tech debt is piling up, paying that price.

*Chorus*
Messy code, messy code, it's a crime,
Spaghetti logic twisted through every line.
Refactor, refactor, before it's too late,
Clean it up, ship it out, let's make code great.

*Verse 2*
Ten levels of nesting, what is this maze?
Been debugging this function for three whole days.
`TODO: fix this` from 2019,
The scariest comment that I've ever seen.

Global variables leaking left and right,
Side effects lurking, hidden out of sight.
No tests, no coverage, just hoping and pray,
Deploy on a Friday — have a nice day.

*Chorus*
Messy code, messy code, it's a crime,
Spaghetti logic twisted through every line.
Refactor, refactor, before it's too late,
Clean it up, ship it out, let's make code great.

*Outro*
So name your variables, write a test or two,
Leave the codebase better than you found it, it's true.
Future you will thank you when the code is clean,
Write the nicest code that anyone has seen.
