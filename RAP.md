# Clean Code Rap 🎤

*A rap about writing clean, clean code*

---

Yo, listen up devs, let me drop some truth,
Clean code's the craft, and here's the proof.
Names that make sense, no mystery here,
`getUserById` — the intent is clear.

Functions stay short, they do one thing,
Single responsibility — let that bell ring.
No magic numbers lurking in the dark,
Name your constants, hit that mark.

**Chorus:**
Clean code, clean code, write it right,
Future you will thank you in the dead of night.
Clean code, clean code, keep it tight,
Readable, maintainable — pure delight.

Comments explain *why*, not *what* you see,
The code itself should speak fluently.
DRY it out, don't repeat yourself twice,
Extract that function — that's the advice.

Tests are your armor, your safety net,
Red to green — no sweat, no regret.
Refactor boldly, the tests have your back,
Stay on the path, don't lose track.

**Chorus:**
Clean code, clean code, write it right,
Future you will thank you in the dead of night.
Clean code, clean code, keep it tight,
Readable, maintainable — pure delight.

Small commits, clear messages, tell the story,
PRs reviewed with care — that's the glory.
Linters running, formatting locked,
Consistent style — the whole team's rocked.

So next time you code, think of the one
Who reads it at midnight when the sprint ain't done.
Write it for humans, not just machines,
Clean code forever — you know what that means.

**Outro:**
Clean. Code. Always. 🙌
